# Green Leaf Cafe Website

A modern, responsive cafe website built with HTML, CSS, and JavaScript featuring a beautiful green theme that emphasizes sustainability and organic values.

## 🌿 Project Overview

This is a complete cafe website showcasing a fictional "Green Leaf Cafe" that specializes in organic, sustainable coffee and food. The website features a modern design with a nature-inspired green color scheme and fully responsive layout.

## ✨ Features

### Design & Theme

- **Green Color Palette**: Multiple shades of green creating a natural, organic feel
- **Modern UI/UX**: Clean, professional design with smooth animations
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Nature-Inspired Icons**: Font Awesome icons representing coffee, plants, and sustainability

### Interactive Elements

- **Mobile Navigation**: Hamburger menu for mobile devices
- **Menu Filtering**: Interactive category buttons (Coffee, Food, Desserts)
- **Smooth Scrolling**: Seamless navigation between sections
- **Hover Effects**: Engaging animations on buttons and menu items
- **Contact Form**: Functional contact form with validation

### Sections

1. **Hero Section**: Eye-catching welcome area with call-to-action buttons
2. **Menu Section**: Interactive menu with category filtering
3. **About Section**: Cafe mission, values, and features
4. **Contact Section**: Location, hours, and contact form
5. **Footer**: Additional links and social media integration

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Modern styling with Flexbox and Grid
- **JavaScript (ES6+)**: Interactive functionality and DOM manipulation
- **Font Awesome**: Icons for visual elements
- **Google Fonts**: Poppins font family for typography

## 🔧 Customization

### Changing Colors

Update the CSS custom properties in `:root` to modify the color scheme:

```css
:root {
  --primary-green: #your-color;
  --secondary-green: #your-color;
  /* ... other colors */
}
```

### Adding Menu Items

Add new menu items in the HTML by duplicating the `.menu-item` structure and updating the content.

### Modifying Content

All text content can be easily updated in the HTML file. The structure is semantic and well-organized for easy editing.
